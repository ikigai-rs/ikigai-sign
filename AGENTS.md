# Working in this repository

`ikigai-sign` is an ikigai module: capability-gated Ed25519 and ES256 signing (`urn:sign:sign`)
and open verification (`urn:sign:verify`), with the signature as an RDF graph. These rules are
for every agent and every person working here. `CLAUDE.md` is a link to this file.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text. Here that is the verify verdict, the signature-graph and every refusal.
- Security reports go through GitHub private vulnerability reporting, never a public issue.
- Every change lands through a pull request with green CI.
- Use American spelling in everything you write: code comments, docs, commit messages and pull
  requests.
